## 快捷命令/会话对话框/粘贴 bug 五项需求（meatshell）

- 粘贴多行出现空行的根因：`i-slint-core` 布局按 `\n` 分段（sharedparley.rs `create_text_paragraphs`），Windows 剪贴板 `\r\n` 残留的 `\r` 让 Parley 再断一次行。修复：vendored Slint `TextInput::insert()` 规范化 CRLF→LF（vendor/EDITOR_PATCH.md 已记录）。
- 本项目通过 `[patch.crates-io]` 使用 vendor/ 下本地补丁版 i-slint-core / i-slint-compiler / i-slint-backend-winit，改 Slint 行为应改 vendor 并同步 EDITOR_PATCH.md。
- 快捷命令弹窗（ui/terminal_view.slint）：分组分页用 `quick-group-list`（Rust `quick_group_list` 生成，与 `quick_cmd_model` 分组顺序一致：default 在前、命名组按字母）+ `quick-page` / `quick-visible-group`；改快捷命令后统一走 `sync_quick_cmd_models()`（app/quick_commands.rs）同时刷新行模型与分组列表。
- 新增快捷命令默认 `qcm-send-enter=false`（app.slint + app.rs 重置点）。
- 自动增高输入框模式：容器 `height: min(cap, max(min, text.preferred-height + padding))`，溢出交给内层 Flickable/ScrollView 滚动；命令栏发送后清空文本自动恢复单行高度。
- 本机（Windows）未安装 Rust 工具链，cargo check/test 无法执行，改动仅静态验证。
